* **The Problem:** 3D Computational Fluid Dynamics (CFD) aerodynamic simulations take 8+ hours per run on high-performance compute clusters.
* **My Solution:** Built an AI surrogate regressor that models CFD aerodynamics in **$< 0.05$ milliseconds with $R^2 > 0.99$**. Integrated EV battery thermal gradient ($\Delta T$) monitoring for thermal runaway prevention and applied **SciPy SLSQP optimization** for real-time active aero flap tuning.
* **Tech:** `Python` `Scikit-Learn` `SciPy` `DuckDB` `Snappy Parquet` `Apache Airflow` `Terraform`

* **Tech:** `Amazon S3` `AWS Glue` `Amazon Athena` `Amazon QuickSight` `Terraform` `SQL`
